# Modbench

An agent harness for GT New Horizons (Minecraft 1.7.10): Forge mods that expose the game over a local
JSON-RPC bridge, and a Python MCP server whose tool modules the model edits and hot-reloads while playing.

Documentation is being consolidated under `docs/`; the previous per-topic notes are in `docs/legacy/`.
See `docs/legacy/LAYERS.md` for the Java / Python / model ownership boundary and `docs/legacy/README.md`
for build and install steps until the new docs land.
